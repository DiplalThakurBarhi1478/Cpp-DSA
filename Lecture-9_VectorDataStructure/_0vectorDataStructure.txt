4. Static and dynamic allocation
    static memory allocation occur at compile time
    dynamic memory allocation occur at run time 

    for example: 
    ------------
    array follows static memory allocation 
    vector follows dynamic memory allocation

    static memory allocation happens in stack
    dynamic memory allocation happens in heap

    Note: in heap during dynamic memory allocation, if the memory is occupied then for every push_back() double the size of the array is created.
    we can understand the difference between size and capacity. 

        Vector in MEMORY
        ----------------
        what do i mean by that? 
        so let say initially we created a vec and push_back 1, then there is one memory
        again i do it, there is no space so double memory will create and the value will be inserted
        now if i push_back again new value inside the vec, since there is no space double size will be created mean 4 memory
        now size is 3 but space is 4, so if i repeat it, then it will insert the value since there is space but no change is capacity.
